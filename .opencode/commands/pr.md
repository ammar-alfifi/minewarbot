---
description: افتح Pull Request للفرع الحالي
---

افتح Pull Request للفرع الحالي إلى `main`، بلا دمج:

1. تأكد أن كل التغييرات مُودَعة ومدفوعة: `git status` يجب أن يكون نظيفاً، وإن لم يكن فيوجد المتبقي باسم commit واضح.
2. أنشئ PR بعنوان واضح بالعربية ووصف موجز يشرح: ماذا تغيّر، ولماذا، وكيف اختُبر.
3. اعرض لي رابط الـ PR فقط.

لا تدمج الـ PR — سيراجعه العضو الآخر أولاً.
