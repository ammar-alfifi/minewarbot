راجع التغييرات الحالية كمراجع كود صارم. **لا تعدّل أي ملف.**

الملفات المتغيرة:
!`git diff --stat && git diff --cached --stat`

الفرق الكامل:
!`git diff && git diff --cached`

ركّز على:
1. ثغرات الأمان: هل يُتحقَّق من `initData`؟ هل يُوثق بأي قيمة أو رصيد قادم من العميل؟
2. صحة منطق اللعبة: الأرصدة، الترقيات، الـ cooldown، حدود الغارات، منع الأرصدة السالبة.
3. القيم الحدية والسباقات (طلبات متزامنة، تكرار الشراء).
4. توافق الواجهة العربية RTL وسلامة `try/catch` حول `tg.*`.

اعرض النتائج مرتبة حسب الخطورة، مع مسار الملف واقتباس السطر. إن لم تجد مشكلة، قل ذلك بصراحة.
