# ⛏️ Mine War — حرب المناجم

لعبة تعدين عربية أولاً داخل **Telegram Mini App**: عدّن بيدك، وظّف عمّالاً يعملون حتى وأنت بعيد، اكتشف الآثار والجواهر، افتح مناطق أعماق جديدة، ونافس أصدقاءك في لوحة صدارة وغارات ودّية.

> البوت: `@MineWarrBot` — التصميم الكامل في [`GAME_PROMPT.md`](./GAME_PROMPT.md)، والأفكار في [`IDEAS.md`](./IDEAS.md).

---

## ✨ ما الذي يميز اللعبة؟

- **جولة تعليمية تفاعلية**: تظهر عند أول دخول (وتُبرز العناصر خطوة بخطوة)، ويمكن إعادتها في أي وقت من زر «؟» في الأعلى.
- **تعدين ممتع وفوري**: زر تعدين كبير، أرقام طائرة، اهتزازات تيليجرام عند توفرها، وتجميع ذكي للنقرات.
- **تقدم حقيقي**: 8 مناطق بأجواء ومضاعفات ومجموعات آثار مختلفة، معدات (معول/مصباح/خوذة)، عمّال، ومرافق (عربة/مسبك/مخزن).
- **اكتشافات نادرة**: جواهر وآثار بندرة (عادي → أسطوري)، ودفتر مجموعة كامل مع ظلال لما لم تكتشفه بعد.
- **اقتصاد عادل على السيرفر**: لا يمكن للواجهة أن تقرر رصيدك أو نتيجة أي غارة أو اكتشاف.
- **أرباح غياب بشفافية**: يعمل عمّالك وأنت بعيد حتى سقف المخزن، ويظهر لك الحساب الدقيق (المدة، المعدل، السقف) بلا عدّادات وهمية.
- **تنافس ودّي**: لوحات (رفاقي / الموسم / الثروة / المجموعة / العام)، غارات بنسبة صغيرة محدودة مع درع وثأر وسجل، وهدف جماعي أسبوعي «الحفرة الجماعية» يشترط مساهمين متعددين.
- **عائد يومي بلا إجبار**: حفرة يومية + مكافأة زيارة بسلّم 7 أيام (الجواهر أسبوعية بعد إكمال السلسلة)، وأحداث أسبوعية متغيرة.
- **حلقة طويلة — بعث المنجم (Rebirth)**: أنهِ دورة كاملة (كل المناطق + 50 مليون تعدين منها 10 ملايين يدوي) لتحصل على **نوى إرث** تفتح شجرة دائمة محدودة (+20% عملات، +20% يدوي، +2 ساعة غياب)، مع الاحتفاظ بالآثار والجواهر والألقاب والسجل.
- **تخصصات المناطق**: كل منطقة تميل لعائد مختلف (يدوي/عمال/اكتشاف/غياب)، فالأعمق ليس دائماً الأفضل.
- **جوائز الموسم ومتجر التجميل**: جائزة مشاركة وتتويج لأفضل 10% وبطل الأسبوع، ومصارف جواهر شكلية بلا تفوق تنافسي.
- **جاهزة للعالم العربي وخارج تيليجرام**: RTL كامل، خطوط نظيفة، دعم ثيم تيليجرام الفاتح/الداكن، ووضع ضيف واضح للتطوير في المتصفح.

## 🚀 تشغيل سريع

### 1) المتطلبات
- Node.js 20+ (مُختبر على 24)
- توكن بوت من [@BotFather](https://t.me/BotFather)

### 2) التثبيت والإعداد
```bash
git clone https://github.com/ammar-alfifi/minewarbot.git
cd minewarbot

npm install   # يثبّت الباكند والواجهة معاً (npm workspaces)

cp backend/.env.example backend/.env
# عدّل backend/.env وضع BOT_TOKEN الحقيقي (لا ترفعه أبداً)
```

### 3) التشغيل
```bash
# نافذة 1 — الباكند والبوت (http://localhost:3001)
npm run dev:backend

# نافذة 2 — الواجهة (http://localhost:5173)
npm run dev:frontend
```

افتح `http://localhost:5173` في المتصفح → ستدخل **وضع الضيف** تلقائياً (واضح وموسوم) لتجربة كل شيء بدون تيليجرام.

### 4) التجربة داخل تيليجرام (HTTPS مطلوب)

أسهل طريقة بدون حساب: نفق Cloudflare مؤقت يخدم نفس الباكند (الذي يقدّم الواجهة المبنية أيضاً):
```bash
npm run build
node backend/src/server.js          # أو npm run dev:backend

# في نافذة أخرى: نفق HTTPS مؤقت مجاني
curl -L -o cloudflared https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64
chmod +x cloudflared
./cloudflared tunnel --url http://localhost:3001
# انسخ الرابط الظاهر https://xxxx.trycloudflare.com
```
ثم حدّث في `backend/.env`:
```
FRONTEND_URL=https://xxxx.trycloudflare.com
ALLOWED_ORIGINS=https://xxxx.trycloudflare.com,http://localhost:5173
```
وأعد تشغيل الباكند، واضبط زر القائمة في BotFather (`/mybots` → Bot Settings → Menu Button) أو تلقائياً عبر:
```bash
curl "https://api.telegram.org/bot<TOKEN>/setChatMenuButton" -H 'Content-Type: application/json' \
  -d '{"menu_button":{"type":"web_app","text":"⛏️ المنجم","web_app":{"url":"https://xxxx.trycloudflare.com"}}}'
```
> النفق المؤقت يتغير رابطه عند كل تشغيل؛ للإنتاج استخدم Cloudflare Workers أو نطاقاً ثابتاً (انظر `DEPLOY.md`). بديل آخر: `ngrok http 3001`.

## 🧪 الأوامر والاختبارات

```bash
npm test            # كل الاختبارات: الباكند (75) + عرض الواجهة (SSR)
npm run build       # بناء واجهة الإنتاج
npm run dev:backend # تشغيل الباكند + البوت (polling)
npm run dev:frontend
npm run cf:dry      # تحقّق من بناء Cloudflare Worker دون نشر
npm run cf:deploy   # نشر على Cloudflare Workers
```

| الأمر | ماذا يفحص |
|---|---|
| `npm test --prefix backend` | معادلات الاقتصاد والبعث وتخصصات المناطق، توقيع initData ورفض القديم/المعدّل، المحرك (تعدين/ترقية/غارة/درع/ثأر/سقف يومي/غياب/إنجازات/إحالات/بعث/إرث/تجميل/ترحيل بيانات)، طبقتا التخزين (JSON وSQLite)، مستودع D1 ومحوّل Cloudflare Worker (تكامل كامل)، ومسارات HTTP |
| `npm run test:render --prefix frontend` | يشغّل الباكند الحقيقي، ينشئ لاعباً ويلعب جولة، ثم يعرض كل الشاشات والنوافذ والجولة التعليمية ببيانات فعلية للتأكد من سلامتها |
| `npm run backup --prefix backend` | نسخة احتياطية JSON لكل اللاعبين (تعمل مع JSON وSQLite) |
| `npm run restore --prefix backend -- <ملف>` | استرجاع نسخة احتياطية |

## 🔌 واجهة الـ API

كل طلبات اللعب مصادَقة بـ `X-Init-Data` (من تيليجرام) أو `Authorization: Bearer <session-token>` (يُصدر بعد أول تحقق ناجح، أو للضيوف في التطوير).

| الطريقة | المسار | الوظيفة |
|---|---|---|
| `GET` | `/api/health` | فحص صحة الخدمة |
| `POST` | `/api/session` | التحقق من initData وإنشاء/تحميل اللاعب وإرجاع الحالة والكاتالوج وتوكن الجلسة |
| `GET` | `/api/state` | الحالة الرسمية + ملخص الغياب + الكاتالوج |
| `POST` | `/api/actions/mine` | تعدين دفعة نقرات (1–25) بحساب السيرفر للنتائج والاكتشافات |
| `POST` | `/api/actions/upgrade` | شراء ترقية أو عامل أو حماسة |
| `POST` | `/api/actions/raid` | غارة/ثأر محدود ومحمي |
| `POST` | `/api/actions/daily` | الحفرة اليومية + درع |
| `POST` | `/api/actions/claim` | استلام إنجاز أو مكافأة جماعية |
| `POST` | `/api/actions/region` | تغيير المنطقة الحالية |
| `POST` | `/api/actions/title` | شراء/تجهيز لقب |
| `POST` | `/api/actions/rebirth` | بعث المنجم (يصفّر الدورة مقابل نوى إرث) |
| `POST` | `/api/actions/legacy` | ترقية مسار في شجرة نوى الإرث |
| `POST` | `/api/actions/cosmetic` | شراء/تجهيز زينة من متجر التجميل |
| `POST` | `/api/actions/notices` | تعليم الإشعارات كمقروءة |
| `POST` | `/api/actions/tutorial` | تسجيل إكمال الجولة التعليمية (تبقى قابلة للإعادة من الواجهة) |
| `GET` | `/api/leaderboard?scope=` | لوحة: `friends` · `season` · `wealth` · `collection` |
| `GET` | `/api/raidlog` | سجل الغارات الواردة/الصادرة + إمكانية الثأر |
| `POST` | `/api/invites` | رابط دعوة/مشاركة |
| `GET` | `/api/catalog` | محتوى اللعبة الثابت (مناطق، آثار، ألقاب، قواعد معلنة) |

كل عملية لعبة تقبل `requestId` اختيارياً؛ إعادة إرسال نفس المعرّف لا تُنفَّذ مرتين.

## 🔒 الأمان ونزاهة اللعب

- **initData يُتحقق منه على السيرفر** بخطوات تيليجرام الرسمية (HMAC-SHA256) مع رفض `auth_date` القديم، والهوية تُشتق من `tg_<user id>` — أي `playerId` من العميل يُتجاهل.
- **وضع الضيف معزول**: يعمل خارج الإنتاج فقط، وهويته توكن موقّع من السيرفر لا يمكن انتحاله.
- **السيرفر هو السلطة**: الأسعار، الأرصدة، الحظر، العشوائية، سقف الغنيمة، مهل الغارات، وسقف أرباح الغياب — كلها محسوبة في `game/rules.js` + `game/engine.js`.
- **حماية من الاستغلال**: قفل تسلسلي لكل التعديلات (لا سباقات شراء/غارة)، حماية إعادة الإرسال بـ `requestId` **إلزامي ومربوط بنوع العملية**، حدود معدل لكل IP ولاعب، وسقف محاولات غارة يومي وحماية للمبتدئين ودرع للضحية.
- **اقتصاد مغلق للغارات**: الغنيمة تُنقل من مخزون الضحية (لا تُطبع من العدم)، وخسارة الفشل 40% منها تُحرق كمصرف عملات.
- **لا مساس بالجواهر أو الآثار في الغارات**، و**مخزن محمي 30%** في مخزون الضحية لا يُلمس، ولا خسارة للمهاجم في الثأر.
- **الأسرار**: `.env` مستثنى من git، و`.env.example` عيّنات فقط، والسجلات لا تطبع التوكن.
- **جلسات قابلة للإبطال**: التوكن يحمل «نسخة جلسة» (`sessionEpoch`)، و`POST /api/actions/logout` يرفعها فيُبطل كل التوكنات السابقة، والعمر الافتراضي 7 أيام (`SESSION_MAX_AGE_MS`).
- **رؤوس أمنية**: `CSP frame-ancestors` تسمح بتضمين تيليجرام فقط + `HSTS` في الإنتاج + `nosniff` و`no-referrer`.
- **قيود تشغيلية**: تخزين JSON/SQLite يفرض **نسخة سيرفر واحدة** (وثيقة حالة واحدة)؛ وعلى Cloudflare حدود المعدل داخل نسخة الـ isolate (best-effort) — للحماية الصارمة عبر العُقد يلزم Durable Object/KV، وللتوسّع الكبير يلزم فصل اللاعبين إلى صفوف.
- **`TRUST_PROXY`**: يُفعَّل افتراضياً في الإنتاج — لا تشغّله إلا خلف وكيل موثوق وإلا أمكن تزوير عنوان IP.
- **البعث (Rebirth)** يُحسب ويُنفَّذ بالكامل على السيرفر: الشروط والنوى والتصفير في `game/rules.js` + `game/engine.js`، ولا تستطيع الواجهة تجاوزها ولا شراء النوى بالجواهر.
- **دخل العمّال** يمنح عملات ويفتح المناطق، لكنه **لا** يضخّم هدف الجماعة الأسبوعي ولا نقاط الموسم (كي لا يحصد اللاعب الخامل السباق).

## 🎮 اللعب باختصار

- **العملات 🪙** من التعدين والعمّال، و**الجواهر 💎** من الاكتشافات والمكافآت (لا تُشترى بمال حقيقي)، و**الآثار 🏺** للمجموعة والبرستيج، و**نوى الإرث ✨** من البعث.
- **المناطق الثماني** تُفتح بتراكم تعدين **الدورة** الحالية، وكل منطقة: مضاعف إنتاج، مجموعة آثار، تخصص عائد مختلف، وتلوين بصري خاص.
- **بعث المنجم (Rebirth)**: يصفّر العملات والعمّال والمعدات والمناطق في الدورة ويعيدك للسطح مقابل نوى تفتح شجرة إرث دائمة محدودة. يبقى دائماً: الآثار، الجواهر، الألقاب، الأصدقاء، مجموع التعدين مدى الحياة، الإنجازات، وسجل المواسم والغارات. عتبة كل دورة ×5 (50M ثم 250M ...) والشرط يتطلب تعديناً يدوياً نشطاً فلا يكفي الدخل الخامل.
- **الترقيات**: معول (قوة ضربة)، مصباح (فرص الاكتشاف)، خوذة (دفاع الغارات)، عربة (إنتاج العمال)، مسبك (قوة يدوية)، مخزن (سقف الغياب)، وعمّال بأسعار تصاعدية.
- **الغارات**: بمخاطرة حقيقية — الغنيمة نسبة من مخزون الخصم (12%) بسقفَين مرتبطَين بالإنتاج (≤15 دقيقة من إنتاج الضحية و≤60 دقيقة من إنتاجك)، ومخزن محمي 30% لا يُلمس. عند الفشل تخسر نسبة من رصيدك (60% منها تعويض للضحية والباقي يُحرق)، وهي **مُلغاة في الثأر**. 8 **محاولات** يومياً (الفشل يُحسب)، غنيمة الثأر ×1.25، ومهلة هدف 15 دقيقة. **حماية المبتدئين**: من تعدينه < 10,000 لا يهاجم ولا يُهاجَم.
- **الحفرة الجماعية**: مساهمة أسبوعية مشتركة من التعدين النشط مع مكافآت شخصية، وصندوق جماعي عند بلوغ الهدف الإجمالي + مساهمين كافيين (3 على الأقل، كلٌّ بـ5,000 مساهمة؛ ويُخفَّض الشرط في مجتمع صغير).
- **المواسم الأسبوعية**: نقاط من التعدين النشط والاكتشافات والغارات (لا من دخل العمّال السلبي)، تُصفَّر أسبوعياً مع حفظ الألقاب والإنجازات الدائمة، وتُمنح جوائز نهاية الأسبوع (مشاركة + تتويج أفضل 10% + جائزة البطل).
- **شجرة نوى الإرث ✨**: ثلاثة مسارات دائمة محدودة (ذاكرة العروق +20% عملات، يد المنقّب +20% يدوي، مخزن السلالة +2 ساعات غياب)، ومتجر تجميل اختياري لا يمنح تفوقاً تنافسياً.
- **حدث الأسبوع**: يدور تلقائياً بين 4 أحداث (عروق غنية، اندفاع الجواهر، موسم الآثار، أيادٍ سريعة).

## ☁️ النشر

الدليل الكامل (Cloudflare Workers، Docker، Oracle Always Free، Fly.io، Render، نطاق ثابت، والنقل) في **[`DEPLOY.md`](./DEPLOY.md)**.

### ⭐ الأسرع والأرخص: Cloudflare Workers + D1 (0$ بلا بطاقة وبلا سيرفر)
الواجهة + الـ API + **webhook البوت** في Worker واحد، والتخزين في D1. لا نوم ولا جهاز مفتوح:
```bash
npx wrangler login
npx wrangler d1 create minewarr          # الصق المعرّف في wrangler.toml
npx wrangler secret put BOT_TOKEN        # وكذا SESSION_SECRET و WEBHOOK_SECRET
npm run cf:deploy
npm run webhook --prefix backend -- https://<مشروعك>.<حسابك>.workers.dev
```
> خطوات اللوحة (بدون أوامر) في `DEPLOY.md`. ربط D1 باسم `DB` ضروري.

### أو Docker على أي سيرفر (بيانات دائمة SQLite) ورابط ثابت
```bash
# أنشئ .env بجانب docker-compose.yml وضع BOT_TOKEN و FRONTEND_URL و SESSION_SECRET
docker compose up -d --build
```
- الباكند يخدم الواجهة والـ API على نفس النطاق (`SERVE_FRONTEND=true`) → لا حاجة لإعداد CORS ولا مشاكل `localhost`.
- البيانات في قرص دائم `/data` — نصيحة: استخدم نفق Cloudflare مُسمّى أو Caddy للحصول على HTTPS ثابت.

> بديل بلا سيرفر تماماً: **Cloudflare Workers + D1** (`cloudflare/`) — الواجهة والـ API والبوت في Worker واحد، بلا نفق وبلا خادم.

## 🧯 استكشاف الأخطاء

| العَرَض | الحل |
|---|---|
| «تعذّر الاتصال بالسيرفر» في المتصفح | تأكد أن الباكند يعمل على `3001` وأن `VITE_API_URL` صحيح |
| البوت لا يرد | `BOT_TOKEN` غير مضبوط أو placeholder — الباكند يعمل لكن البوت معطّل |
| «انتهت صلاحية الجلسة» في تيليجرام | أعد فتح التطبيق من الزر داخل البوت |
| الواجهة لا تفتح داخل تيليجرام | يجب HTTPS — استخدم ngrok وحدّث `FRONTEND_URL` وBotFather |
| تضارب polling | شغّل نسخة واحدة فقط بنفس التوكن |
