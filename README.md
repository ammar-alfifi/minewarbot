# ⛏️ Mine War — حرب المناجم

لعبة تعدين عربية أولاً داخل **Telegram Mini App**: عدّن بيدك، وظّف عمّالاً يعملون حتى وأنت بعيد، اكتشف الآثار والجواهر، افتح مناطق أعماق جديدة، ونافس أصدقاءك في لوحة صدارة وغارات ودّية.

> البوت: `@MineWarrBot` — التصميم الكامل في [`GAME_PROMPT.md`](./GAME_PROMPT.md)، والأفكار في [`IDEAS.md`](./IDEAS.md).

---

## ✨ ما الذي يميز اللعبة؟

- **تعدين ممتع وفوري**: زر تعدين كبير، أرقام طائرة، اهتزازات تيليجرام عند توفرها، وتجميع ذكي للنقرات.
- **تقدم حقيقي**: 8 مناطق بأجواء ومضاعفات ومجموعات آثار مختلفة، معدات (معول/مصباح/خوذة)، عمّال، ومرافق (عربة/مسبك/مخزن).
- **اكتشافات نادرة**: جواهر وآثار بندرة (عادي → أسطوري)، ودفتر مجموعة كامل مع ظلال لما لم تكتشفه بعد.
- **اقتصاد عادل على السيرفر**: لا يمكن للواجهة أن تقرر رصيدك أو نتيجة أي غارة أو اكتشاف.
- **أرباح غياب بشفافية**: يعمل عمّالك وأنت بعيد حتى سقف المخزن، ويظهر لك الحساب الدقيق (المدة، المعدل، السقف) بلا عدّادات وهمية.
- **تنافس ودّي**: لوحات (رفاقي / الموسم / الثروة / المجموعة / العام)، غارات بنسبة صغيرة محدودة مع درع وثأر وسجل، وهدف جماعي أسبوعي «الحفرة الجماعية».
- **عائد يومي بلا إجبار**: حفرة يومية + مكافأة زيارة بسلّم 7 أيام، وأحداث أسبوعية متغيرة.
- **جاهزة للعالم العربي وخارج تيليجرام**: RTL كامل، خطوط نظيفة، دعم ثيم تيليجرام الفاتح/الداكن، ووضع ضيف واضح للتطوير في المتصفح.

## 🚀 تشغيل سريع

### 1) المتطلبات
- Node.js 20+ (مُختبر على 24)
- توكن بوت من [@BotFather](https://t.me/BotFather)

### 2) التثبيت والإعداد
```bash
git clone https://github.com/ammar-alfifi/minewarbot.git
cd minewarbot

npm install   # يثبّت الباكند والواجهة معاً (npm workspaces)

cp backend/.env.example backend/.env
# عدّل backend/.env وضع BOT_TOKEN الحقيقي (لا ترفعه أبداً)
```

### 3) التشغيل
```bash
# نافذة 1 — الباكند والبوت (http://localhost:3001)
npm run dev:backend

# نافذة 2 — الواجهة (http://localhost:5173)
npm run dev:frontend
```

افتح `http://localhost:5173` في المتصفح → ستدخل **وضع الضيف** تلقائياً (واضح وموسوم) لتجربة كل شيء بدون تيليجرام.

### 4) التجربة داخل تيليجرام (HTTPS مطلوب)

أسهل طريقة بدون حساب: نفق Cloudflare مؤقت يخدم نفس الباكند (الذي يقدّم الواجهة المبنية أيضاً):
```bash
npm run build
node backend/src/server.js          # أو npm run dev:backend

# في نافذة أخرى: نفق HTTPS مؤقت مجاني
curl -L -o cloudflared https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64
chmod +x cloudflared
./cloudflared tunnel --url http://localhost:3001
# انسخ الرابط الظاهر https://xxxx.trycloudflare.com
```
ثم حدّث في `backend/.env`:
```
FRONTEND_URL=https://xxxx.trycloudflare.com
ALLOWED_ORIGINS=https://xxxx.trycloudflare.com,http://localhost:5173
```
وأعد تشغيل الباكند، واضبط زر القائمة في BotFather (`/mybots` → Bot Settings → Menu Button) أو تلقائياً عبر:
```bash
curl "https://api.telegram.org/bot<TOKEN>/setChatMenuButton" -H 'Content-Type: application/json' \
  -d '{"menu_button":{"type":"web_app","text":"⛏️ المنجم","web_app":{"url":"https://xxxx.trycloudflare.com"}}}'
```
> النفق المؤقت يتغير رابطه عند كل تشغيل؛ للإنتاج استخدم نطاقاً ثابتاً (Vercel/Render). بديل آخر: `ngrok http 3001`.

## 🧪 الأوامر والاختبارات

```bash
npm test            # كل الاختبارات: الباكند (46) + عرض الواجهة (SSR)
npm run build       # بناء واجهة الإنتاج
npm run dev:backend # تشغيل الباكند + البوت (polling)
npm run dev:frontend
```

| الأمر | ماذا يفحص |
|---|---|
| `npm test --prefix backend` | معادلات الاقتصاد، توقيع initData ورفض القديم/المعدّل، المحرك (تعدين/ترقية/غارة/درع/ثأر/سقف يومي/غياب/إنجازات/إحالات/ترحيل بيانات)، ومسارات HTTP كاملة |
| `npm run test:render --prefix frontend` | يشغّل الباكند الحقيقي، ينشئ لاعباً ويلعب جولة، ثم يعرض كل الشاشات والنوافذ ببيانات فعلية للتأكد من سلامتها |

## ⚙️ متغيرات البيئة (backend/.env)

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `BOT_TOKEN` | — | توكن البوت من BotFather (سرّي) |
| `BOT_USERNAME` | `MineWarrBot` | اسم البوت لروابط الدعوة |
| `PORT` | `3001` | منفذ الـ API |
| `NODE_ENV` | — | `production` يفعّل تشديد CORS ويعطّل وضع الضيوف تلقائياً |
| `FRONTEND_URL` | `http://localhost:5173` | رابط الواجهة |
| `ALLOWED_ORIGINS` | قيمة `FRONTEND_URL` | نطاقات CORS مسموحة (مفصولة بفواصل) |
| `ALLOW_GUEST` | `true` خارج الإنتاج | وضع الضيف للتطوير |
| `INIT_DATA_MAX_AGE_SEC` | `86400` | صلاحية `auth_date` قبل الرفض |
| `SESSION_SECRET` | مشتق/عشوائي | توقيع توكنات الجلسة (ضعه في الإنتاج) |
| `DATA_FILE` | `./data/players.json` | ملف التخزين |
| `SERVE_FRONTEND` | `true` | خدمة `frontend/dist` من الباكند |
| `TRUST_PROXY` | `true` في الإنتاج | قراءة IP الحقيقي خلف منصات النشر |

## 🔌 واجهة الـ API

كل طلبات اللعب مصادَقة بـ `X-Init-Data` (من تيليجرام) أو `Authorization: Bearer <session-token>` (يُصدر بعد أول تحقق ناجح، أو للضيوف في التطوير).

| الطريقة | المسار | الوظيفة |
|---|---|---|
| `GET` | `/api/health` | فحص صحة الخدمة |
| `POST` | `/api/session` | التحقق من initData وإنشاء/تحميل اللاعب وإرجاع الحالة والكاتالوج وتوكن الجلسة |
| `GET` | `/api/state` | الحالة الرسمية + ملخص الغياب + الكاتالوج |
| `POST` | `/api/actions/mine` | تعدين دفعة نقرات (1–25) بحساب السيرفر للنتائج والاكتشافات |
| `POST` | `/api/actions/upgrade` | شراء ترقية أو عامل أو حماسة |
| `POST` | `/api/actions/raid` | غارة/ثأر محدود ومحمي |
| `POST` | `/api/actions/daily` | الحفرة اليومية + درع |
| `POST` | `/api/actions/claim` | استلام إنجاز أو مكافأة جماعية |
| `POST` | `/api/actions/region` | تغيير المنطقة الحالية |
| `POST` | `/api/actions/title` | شراء/تجهيز لقب |
| `POST` | `/api/actions/notices` | تعليم الإشعارات كمقروءة |
| `GET` | `/api/leaderboard?scope=` | لوحة: `friends` · `season` · `wealth` · `collection` |
| `GET` | `/api/raidlog` | سجل الغارات الواردة/الصادرة + إمكانية الثأر |
| `POST` | `/api/invites` | رابط دعوة/مشاركة |
| `GET` | `/api/catalog` | محتوى اللعبة الثابت (مناطق، آثار، ألقاب، قواعد معلنة) |

كل عملية لعبة تقبل `requestId` اختيارياً؛ إعادة إرسال نفس المعرّف لا تُنفَّذ مرتين.

## 🔒 الأمان ونزاهة اللعب

- **initData يُتحقق منه على السيرفر** بخطوات تيليجرام الرسمية (HMAC-SHA256) مع رفض `auth_date` القديم، والهوية تُشتق من `tg_<user id>` — أي `playerId` من العميل يُتجاهل.
- **وضع الضيف معزول**: يعمل خارج الإنتاج فقط، وهويته توكن موقّع من السيرفر لا يمكن انتحاله.
- **السيرفر هو السلطة**: الأسعار، الأرصدة، الحظر، العشوائية، سقف الغنيمة، مهل الغارات، وسقف أرباح الغياب — كلها محسوبة في `game/rules.js` + `game/engine.js`.
- **حماية من الاستغلال**: قفل تسلسلي لكل التعديلات (لا سباقات شراء/غارة)، حماية إعادة الإرسال بـ `requestId`، حدود معدل لكل IP ولاعب، وسقف غارات يومي ودرع للضحية.
- **لا مساس بالجواهر أو الآثار في الغارات**، ولا نزول تحت أرضية آمنة لرصيد الضحية.
- **الأسرار**: `.env` مستثنى من git، و`.env.example` عيّنات فقط، والسجلات لا تطبع التوكن.

## 🎮 اللعب باختصار

- **العملات 🪙** من التعدين والعمّال، و**الجواهر 💎** من الاكتشافات والمكافآت (لا تُشترى بمال حقيقي)، و**الآثار 🏺** للمجموعة والبرستيج.
- **المناطق الثماني** تُفتح بتراكم التعدين، وكل منطقة: مضاعف إنتاج، مجموعة آثار، وتلوين بصري خاص.
- **الترقيات**: معول (قوة ضربة)، مصباح (فرص الاكتشاف)، خوذة (دفاع الغارات)، عربة (إنتاج العمال)، مسبك (قوة يدوية)، مخزن (سقف الغياب)، وعمّال بأسعار تصاعدية.
- **الغارات**: نجاح محسوب من موازين القوى، غنيمة بحد أقصى (5% وسقف ثابت)، مهلة 10 دقائق، 5 نجاحات يومياً، درع 3 ساعات للضحية + ثأر خلال 24 ساعة، وسجل واضح للطرفين.
- **الحفرة الجماعية**: مساهمة أسبوعية مشتركة مع مكافآت شخصية وصندوق جماعي عند بلوغ الهدف.
- **المواسم الأسبوعية**: نقاط من التعدين والاكتشافات والغارات، تُصفَّر أسبوعياً مع حفظ الألقاب والإنجازات الدائمة.
- **حدث الأسبوع**: يدور تلقائياً بين 4 أحداث (عروق غنية، اندفاع الجواهر، موسم الآثار، أيادٍ سريعة).

## ☁️ النشر

**خيار 1 — خدمتان:**
- الواجهة: Vercel من مجلد `frontend/` مع `VITE_API_URL=https://api.example.com`
- الباكند: Render/Railway من `backend/` مع `BOT_TOKEN` و`NODE_ENV=production` و`ALLOWED_ORIGINS=https://your-app.vercel.app`
- حدّث Menu Button في BotFather لرابط الواجهة.

**خيار 2 — خدمة واحدة (الأبسط):** انشر الباكند فقط مع بناء الواجهة:
```bash
npm run install:all && npm run build
NODE_ENV=production node backend/src/server.js
```
سيخدم الباكند `frontend/dist` على نفس النطاق (لا حاجة لـ CORS).

> ملاحظة: التخزين JSON المحلي مناسب للـ MVP؛ كل الوصول يمر عبر `backend/src/store.js` فيمكن استبداله بـ SQLite/PostgreSQL دون تغيير قواعد اللعبة.

## 🧯 استكشاف الأخطاء

| العَرَض | الحل |
|---|---|
| «تعذّر الاتصال بالسيرفر» في المتصفح | تأكد أن الباكند يعمل على `3001` وأن `VITE_API_URL` صحيح |
| البوت لا يرد | `BOT_TOKEN` غير مضبوط أو placeholder — الباكند يعمل لكن البوت معطّل |
| «انتهت صلاحية الجلسة» في تيليجرام | أعد فتح التطبيق من الزر داخل البوت |
| الواجهة لا تفتح داخل تيليجرام | يجب HTTPS — استخدم ngrok وحدّث `FRONTEND_URL` وBotFather |
| تضارب polling | شغّل نسخة واحدة فقط بنفس التوكن |
